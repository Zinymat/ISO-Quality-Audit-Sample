# CASE STUDY: Implementing ISO 9001:2015 Data Integrity Framework

## 📌 Project Overview
As a Certified Internal Auditor, I designed a protocol to ensure 99.9% data accuracy during the migration of legacy paper records into a digital database for an international client.

---

## 🔍 The Challenge
The organization relied on manual, paper-based records that were:
- Prone to human error during entry.
- Difficult to retrieve for real-time reporting.
- Non-compliant with modern data security standards.

## 🛠️ My Audit Methodology (ISO 9001:2015)
I applied the **Plan-Do-Check-Act (PDCA)** cycle to solve this:

### 1. Planning (Clause 6)
I identified risks associated with data migration, such as loss of records or duplication.

### 2. Operational Control (Clause 8)
- **Standardized Templates:** Created custom reporting templates to ensure data consistency.
- **Verification Protocols:** Implemented a double-entry verification system for high-priority records.

### 3. Performance Evaluation (Clause 9)
Conducted internal audits to measure the accuracy of the new digital database against the original source documents.

---

## 🏆 Key Achievements
- **Accuracy:** Reached a verified **99.9% accuracy rate** in database entries.
- **Accessibility:** Reduced team data-search time from hours to seconds through streamlined categorization.
- **Security:** Implemented security measures to protect sensitive data during and after migration.
